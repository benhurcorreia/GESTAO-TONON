# Gestão Tonon — demonstração

Demonstração responsiva de acompanhamento de fazendas leiteiras, com dados fictícios. Inclui painel, gráficos, histórico por fazenda, prévia do formulário de visitas e relatório PDF demonstrativo.

## Abrir online

Em **Settings → Pages**, escolha **Deploy from a branch**, branch **main** e pasta **/ (root)**, e clique em **Save**. O GitHub informará o endereço quando a publicação terminar.

Endereço esperado após ativação: https://benhurcorreia.github.io/GESTAO-TONON/

O repositório pode permanecer privado se o plano da conta permitir GitHub Pages em repositórios privados. Caso a opção não esteja disponível, o proprietário precisa escolher entre um plano compatível e tornar este repositório público. O site do Pages pode ser público mesmo quando o repositório é privado.

## Escopo

Esta versão serve para apresentação. Não recebe dados reais, não oferece login operacional e não salva visitas. Os dados são fictícios e identificados como demonstração. O aplicativo completo exige servidor, autenticação e armazenamento separados.

Para abrir sem hospedagem, baixe `index.html` e abra em um navegador. A interface se adapta a celular e computador.
